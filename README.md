# Persian RTL for AI Chat

پلاگین JetBrains برای راست‌به‌چپ کردن متن فارسی در چت **AI Assistant**: هم پیام‌هایی که می‌فرستید، هم جواب‌های AI، هم کادر نوشتن پرامپت.

## نصب

1. `Settings → Plugins → ⚙ → Install Plugin from Disk…`
2. فایل `dist/persian-rtl-ai-chat-1.0.1.zip` را انتخاب کنید.
3. IDE را ری‌استارت کنید.

تنظیمات: `Settings → Tools → Persian RTL for AI Chat`

## چه کار می‌کند

| بخش | رفتار |
|---|---|
| پیام‌های چت (شما و AI) | جهت هر پاراگراف جداگانه تعیین می‌شود. اگر پاراگراف با حرف فارسی شروع شود یا بیشتر حروفش فارسی باشد، راست‌به‌چپ و راست‌چین می‌شود. متن انگلیسی و کد چپ‌به‌راست می‌مانند. |
| کادر پرامپت | وقتی متن فارسی باشد، جهت و تراز کادر راست‌به‌چپ می‌شود. |
| (اختیاری، پیش‌فرض خاموش) آینه‌کردن کل پنل چت | کل چیدمان چت راست‌به‌چپ می‌شود، حتی پاراگراف‌های انگلیسی و کد. |

## نحوه کار (فنی)

- چت AI Assistant با Compose/Jewel رسم می‌شود. Compose وقتی جهت متن مشخص نشده باشد، آن را از جهت چیدمان می‌گیرد، که در IDE همیشه LTR است. پلاگین با یک agent کوچک که به خود IDE وصل می‌شود (`-Djdk.attach.allowAttachSelf=true` به‌صورت پیش‌فرض در IDEهای JetBrains فعال است)، دو متد Compose را در زمان اجرا patch می‌کند تا جهت از روی محتوای متن تعیین شود. این تغییر روی همه متن‌های Compose در IDE اثر دارد، اما فقط پاراگراف‌های فارسی/عربی/عبری را تغییر می‌دهد. با خاموش کردن گزینه، patch برداشته می‌شود.
- کادر پرامپت یک editor معمولی IntelliJ است. پلاگین فقط برای همان editor جهت BiDi را روی RTL می‌گذارد و آن را راست‌چین می‌کند.
- editor الگوریتم BiDi را برای هر token جداگانه اجرا می‌کند و lexer کادر پرامپت (زبان `ChatInput`) هر کلمه را یک token جدا حساب می‌کند. برای همین «سلام خوبی» به‌صورت «خوبی سلام» نمایش داده می‌شد. پلاگین برای زبان `ChatInput` یک `bidiRegionsSeparator` ثبت می‌کند تا هر خط یک پاراگراف BiDi حساب شود، همان رفتاری که plain text دارد.
- پیام‌هایی که قبل از فعال شدن پلاگین رسم شده‌اند، بعد از باز و بسته کردن چت درست نمایش داده می‌شوند.

## Build

به Gradle نیاز ندارد. با jarهای یک IDE نصب‌شده کامپایل می‌شود:

```bash
./build.sh                                   # IDE را خودش پیدا می‌کند
IDE_HOME=~/Applications/PhpStorm.app/Contents ./build.sh
```

`test/src/.../PatchSmokeTest.java` بدون IDE بررسی می‌کند که patch واقعاً چیدمان متن Skia را عوض می‌کند (قبل/بعد/برگرداندن patch).
